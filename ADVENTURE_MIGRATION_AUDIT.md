## Baseline and decision record

The pre-change baseline was `node --test`: 264 passing tests. Repository scripts expose Vite build/dev commands but no separate inspection package, so `rg`, `node --check`, `node --test`, and `npm run build` are the available inspection/static/focused/full validation tools.

Whole-number Orb capacity uses nearest-integer rounding. The literal requested multiplier `0.33333` evaluates to `3.99996` at the base capacity; flooring would violate the required base Orb capacity of 4. Nearest rounding preserves that acceptance value and applies consistently to upgrades.
